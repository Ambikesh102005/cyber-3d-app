# 🌌 AINDRA 3D Cyber-Nexus

A high-performance, futuristic 3D Web Application built with **Three.js**, **WebGL**, and **Python Flask**. Features interactive hardware-accelerated 3D geometries, particle systems, and glassmorphic cyberpunk UI.

## 🚀 Live Demo
🌐 **App URL:** [Cyber 3D App Live](https://cyber-3d-app.onrender.com) *(Update with your Render URL)*

## 🛠️ Tech Stack
- **Frontend:** Three.js (WebGL), HTML5, CSS3, Vanilla JavaScript
- **Backend:** Python (Flask), Gunicorn
- **Deployment:** Render (PaaS)
- **Design:** Cyberpunk Glassmorphism UI
